## Root causes and permanent fixes

- Big 12 now uses a compact range heading (`Games on November 6-7, 2026`) and abbreviated per-game footers (`Fri. 11/6`, `Sat. 11/7`). The old parser rejected this layout. The fix reads each game’s explicit footer date separately and preserves exact identity/date matching. A range without readable individual dates still fails closed.
- A bounded manual correction could block a newer same-week official report. Explicit source publication times now determine whether the official report supersedes it. Missing times do not establish freshness; an ordinary weekly OUT cannot erase a more specific season-ending absence. Stale, future or unknown-time reports cannot replace a newer report whose posting time is known.
- An improved designation could retain a published zero override from a prior OUT. The existing shared helper now retires unlocked zero overrides for uncertain/returned statuses while preserving the original forecasts and locked snapshots. Repeated unchanged reports can repair this legacy state without duplicate news.

The live update used the tested importer in a short-lived operator process. The persistent scheduled-import fix is in the associated code change; no production files were hot-patched. Normal application injury-alert rules remain intact; unchanged report timestamps do not generate duplicate alerts.
